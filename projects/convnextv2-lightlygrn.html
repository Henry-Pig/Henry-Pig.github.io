ConvNeXt V2 论文复现与改进

本项目围绕 ConvNeXt V2 的论文复现与 GRN 模块改进展开。在理解原始 ConvNeXt V2、FCMAE 和 GRN 的基础上，进一步实现 LightlyGRN 与 DGRN 等改进方案，并通过 CIFAR-100 微调实验比较不同模块对模型性能、参数量与训练表现的影响。

时间

背景与动机

ConvNeXt V2 将全卷积掩码自编码器 FCMAE 与全局响应归一化 GRN 共同设计。根据项目汇报材料，直接把 MAE 套到卷积网络上会受到密集滑动窗口带来的掩码区域信息泄露影响，ConvNeXt 特征中也可能出现通道激活冗余与特征坍缩；FCMAE 负责解决卷积网络的掩码自编码预训练形式，GRN 则通过全局响应归一化增强通道之间的竞争。

技术路线

01

复现原始模型

阅读 ConvNeXt V2 官方实现，在本地算力约束下复现 Tiny 模型的微调流程。

02

理解 FCMAE 与 GRN

分析基于稀疏卷积的 FCMAE 预训练流程，以及 GRN 的 L2 全局响应聚合、通道归一化、仿射校准与残差连接。

03

实现 LightlyGRN

使用 1x1 降维、深度卷积、低维响应归一化与升维恢复，作为原文 GRN 的轻量化替代路径。

04

探索 DGRN

汇报材料将 DGRN 设计为带轻量门控分支的动态 GRN 变体，希望让特征校准权重随输入自适应变化。

核心改进

  • 原始 GRN 对空间维度进行 L2 范数聚合，再用通道平均响应进行归一化，最后通过可学习的 gamma / beta 与残差连接完成特征校准。
  • LightlyGRN 在提交代码中以 MobileGRN 形式实现：先将特征从 C 通道投影到 C/r 通道，在低维空间进行深度卷积与响应归一化，再升维回 C 通道，目标是降低高维特征上直接归一化的计算压力。
  • DGRN 在汇报材料中被描述为保留 GRN 主干，同时增加动态门控分支：1x1 降维、GELU、1x1 升维与 Sigmoid 权重，使归一化响应能够进行自适应调制。
  • 受单张 RTX 4060 算力与 ImageNet-1K 数据规模限制，项目策略从完整 800 epoch 预训练调整为在 CIFAR-100 上直接微调，并增加日志记录用于实验分析。

个人贡献

根据项目汇报、代码结构与提交材料整理。

  • 负责基线复现与微调流程搭建，将原始 ConvNeXt V2 代码适配到本地 CIFAR-100 实验设置。
  • 作为代码集成负责人，将 MobileGRN / LightlyGRN 与 DGRN 相关改动整合到 utils.py、convnextv2.py、fcmae.py、convnextv2_sparse.py 等核心脚本。
  • 解决 MinkowskiEngine 依赖错误、ImportError、TypeError 等调试问题，并主导确定从完整预训练转向直接微调的实验策略。
